How it counts

One prompt is an agent loop: each step re-sends the whole conversation, so input grows every step. Step 1 sends the starting context; step n sends that plus n−1 growth increments.

Output is billed as visible tokens plus reasoning tokens — reasoning bills at the output rate on every model here.

Assumptions you can move

  • Reasoning-token volume at default effort is an estimate per model, not a published figure. The slider scales it.
  • Cache hit rate defaults to 70% — typical for an agent loop with a stable prefix.
  • Markup × is 1.0: this meters the raw model cost. Lemonade's own margin is not published — if you observe that a prompt costs 3× this, set 3.
